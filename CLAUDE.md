# Стенд личного кабинета Coral Club: запуск для человека без технических навыков

Если человек просит запустить проект («запусти этот проект на локальном сервере», «запусти», «подними», «установи всё необходимое»), сделай всё сам. Не проси вводить команды, не показывай технические детали, отвечай по-русски, коротко и простыми словами. Код не меняй, ничего не коммить.

## Что это за проект

Тестовый стенд: окно входа в личный кабинет Coral Club и главная в духе банковского приложения (баланс, трансферный счёт, быстрые действия, показатели, история заказов, движение бонусов). Данные берёт из настоящего API кабинета (`coralclub.ru`). Нужен интернет. Зависимостей из npm нет, нужен только Node.js 20 или новее.

## Что сделать, по порядку

1. **Node.** Выполни `node -v`. Нужна версия 20 и выше. Если Node нет или версия старая: скажи одной фразой, что нужно поставить Node.js 20, и поставь сам (на Mac `brew install node@20`; если нет brew, через nvm: `nvm install 20`; если не получилось, дай ссылку https://nodejs.org, попроси поставить и написать «готово»). После установки продолжай. Устанавливать пакеты через `npm install` не нужно, их нет.
2. **Порт.** Стенд работает на порту 3300. Проверь, свободен ли он (`lsof -nP -iTCP:3300 -sTCP:LISTEN`). Если занят другим процессом, запусти на другом порту: `LK_PORT=3310 node server.mjs`, и дальше используй его. Чужие процессы не останавливай.
3. **Запуск в фоне.**
   - Если у тебя есть инструмент `preview_start` (приложение Claude Code), запусти им конфигурацию `lk-stand` (описана в `.claude/launch.json`).
   - Иначе через Bash в фоне: `node server.mjs` (или с `LK_PORT=…`). Процесс должен работать, пока человек пробует.
4. **Проверка.** Адрес `http://localhost:3300/lk/state` должен вернуть ответ 200 (на другом порту подставь его). Если нет, прочитай вывод сервера, исправь причину (порт, версия Node) и запусти снова. Лог человеку не показывай.
5. **Открой** страницу `http://localhost:3300` во встроенном браузере (если он есть), иначе дай ссылку.
6. **Скажи человеку** простыми словами: стенд запущен, вот ссылка. На странице нужно войти **тестовой учётной записью кабинета** (логин и пароль у неё должны быть от владельца проекта). После входа откроется главная со счётом, показателями, историей заказов и движением бонусов.

## Правила безопасности

- **Логин и пароль не запрашивай и не вводи сам** ни в форму, ни в команды, ни в файлы. Человек вводит их в форме на странице сам. Пароль нигде не сохраняется и не пишется в лог.
- Запросы к API кабинета идут от её имени, **только чтение**, кроме двух действий, которые человек запускает сам кнопками «Перевод баллов» и «Перевод бонусов». Это реальные переводы в кабинете (перед отправкой стенд спрашивает подтверждение). Сам их не нажимай и не отправляй такие запросы.
- Не открывай стенд для других компьютеров: он слушает только этот компьютер (127.0.0.1), так и оставь.
- Данные тестового аккаунта не копируй в файлы и не отправляй никуда.

## Если что-то не работает

- «Сессия истекла, войдите снова»: просто войти ещё раз (сессия хранится в памяти сервера, перезапуск сервера тоже выходит из аккаунта).
- На экране «нет данных» у трансферного счёта или «Показатели недоступны (403)»: это ответ самого кабинета для этого аккаунта (у потребителей нет показателей), не поломка.
- Страница не открывается: проверь, что сервер запущен, и порт тот же.

## Остановить

На просьбу «останови» или «закрой проект» останови процесс, который запускала ты, и скажи, что всё остановлено.

## Где что лежит (если спросят)

`server.mjs` (маленький сервер: вход и запросы к магазину), `docs/` (экран входа и главная: `home.js`, `metrics.js`, `app.js`), `docs/config.json` (адрес магазина и параметры сессии API), `docs/client.js` (связь с API: через сервер или напрямую), `README.md`.
